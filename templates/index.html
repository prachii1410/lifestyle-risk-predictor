About This Project

The Problem

Daily lifestyle factors such as sleep deprivation, excessive caffeine, screen overexposure, and high workloads can influence how people experience stress and overthinking. Recognizing these patterns early can promote proactive wellness habits.

The Solution

This project uses synthetic lifestyle telemetry and a Random Forest machine learning model to estimate a daily risk score. It is designed for educational demonstration of applied machine learning in a wellness context.

Important Note

This project is created for educational and wellness analytics purposes. It does not diagnose anxiety, mental health disorders, or any medical condition. For mental health concerns, please consult a qualified healthcare professional.
