# 🧠 Lifestyle Telemetry & Overthinking Risk Predictor

> An AI-powered lifestyle analytics web application that uses machine learning to estimate a daily overthinking/stress risk score based on everyday habits.

---

## ⚠️ Disclaimer

**This project is created for educational and wellness analytics purposes only.**

For any personal health concerns, please consult a qualified healthcare professional.

## 📋 Overview

The **Lifestyle Telemetry & Overthinking Risk Predictor** analyzes eight daily lifestyle factors and returns a risk score from **0 to 100**, categorized as:

| Score | Category      |
|-------|---------------|
| 0–34  | Low Risk      |
| 35–64 | Moderate Risk |
| 65–100| High Risk     |

The system uses a **Random Forest Regressor** trained on 1,500 rows of synthetic lifestyle telemetry data to make predictions.

## 🤖 Machine Learning Approach

### Algorithm
**Random Forest Regressor** — an ensemble of 200 decision trees that average their predictions to produce the final risk score. This reduces variance and improves robustness over a single decision tree.

### Dataset
A synthetic lifestyle telemetry dataset of **1,500 rows** with the following columns:

| Column                       | Range        | Description              |
|------------------------------|--------------|--------------------------|
| `sleep_hours`                | 0–12         | Hours of sleep           |
| `caffeine_mg`                | 0–600        | Caffeine intake in mg    |
| `screen_time_hours`          | 0–16         | Daily screen exposure    |
| `workload_level`             | 1–10         | Perceived workload       |
| `physical_activity_minutes`  | 0–180        | Exercise in minutes      |
| `study_hours`                | 0–16         | Study or work hours      |
| `break_frequency`            | 0–20         | Number of breaks taken   |
| `mood_score`                 | 1–10         | Subjective mood rating   |
| `overthinking_risk_score`    | 0–100        | **Target variable**      |

### Target construction (non-linear)
The synthetic target encodes realistic relationships:
- Lower sleep → exponentially higher risk
- Higher caffeine, screen time, workload → higher risk (power curves)
- Higher physical activity, breaks, mood → lower risk
- Interaction terms: (caffeine × inverse sleep) adds extra risk
- Gaussian noise added to prevent trivial linear fitting

### Training pipeline
1. Load dataset (auto-generate if missing)
2. Check for missing values
3. Train/test split (80/20)
4. StandardScaler preprocessing
5. Train RandomForestRegressor (200 trees, max_depth=12)
6. Evaluate: MAE, MSE, RMSE, R²
7. Save model + scaler + metrics JSON

## 🚀 Installation & Setup

### Prerequisites
- Python 3.8 or higher
- pip

### 1. Clone / open the project

```bash
cd lifestyle-risk-predictor
```

### 2. Install dependencies

```bash
pip install -r requirements.txt
```

### 3. Train the model

This generates the synthetic dataset and trains the Random Forest model:

```bash
python model/train_model.py
```

Expected output:
```
[1/8] Loading dataset...
...
  MAE  (Mean Absolute Error):       X.XXXX
  RMSE (Root Mean Squared Error):   X.XXXX
  R²   (Coefficient of Determination): 0.XXXX
[✓] Training complete. Run: python app.py
```

### 4. Run the application

```bash
python app.py
```

### 5. Open in browser

```
http://127.0.0.1:5000
```

## 📖 How to Use

1. **Landing page** — click **Analyze My Day** or scroll to the form.
2. **Adjust sliders** — set your lifestyle values for today. Click **Try Demo Data** to auto-fill example values.
3. **Click "Analyze My Day →"** — the form submits to the Flask backend.
4. **Result page** — view your risk score, gauge chart, insights, and factor breakdown.
5. **Dashboard** — click **View Dashboard** to see metric cards, charts, and the data explorer.
6. **History** — scroll to *Previous Analyses* on the home page to revisit past results.
7. **Dark mode** — click the 🌙 toggle in the navigation bar.

## 📊 Model Evaluation

Typical performance on the synthetic dataset (may vary slightly by run):

| Metric | Typical Value |
|--------|---------------|
| MAE    | ~3–5 points   |
| RMSE   | ~4–7 points   |
| R²     | ~0.94–0.97    |

High R² is expected because the target is a deterministic function of the inputs plus controlled Gaussian noise — this demonstrates the pipeline works correctly on the synthetic data. In a real-world scenario with human-reported data, R² would be considerably lower.
